# BiblioCommons Branch Switcher

Adds a "View on GRPL" / "View on KDL" button to book detail pages on
grpl.bibliocommons.com and kdl.bibliocommons.com, linking to the same
record on the other branch's site.

## Install (unpacked, for personal use)

1. Open `chrome://extensions` in Chrome.
2. Turn on "Developer mode" (top right).
3. Click "Load unpacked".
4. Select this folder (`BiblioCommons Branch Switcher`).

The button will appear on any `/v2/record/...` page on either subdomain,
as the last item in the availability/hold panel.
